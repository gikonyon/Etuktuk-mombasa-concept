# Assumptions register

Every number in the model is one of three kinds.

- **Concept paper**: taken from the author's concept paper for the pilot.
- **Working assumption**: a reasonable figure used to run the model, to be checked against evidence.
- **Placeholder**: not sourced. It exists only so the model runs. Replace before relying on any output.

## What would make this project referable
1. A supplier quote.
2. A funder or lender indication on rates.
3. A short Mombasa operator survey, with anonymised results published in the repository.
4. One named credit professional reviewing the assumptions.

## What is deliberately not estimated
- Women's economic empowerment: no data yet. A development-finance indicator that should be measured, with a target set.
- Tax revenues: no basis for an estimate.
- Jobs: operators are probably already driving, so the model reports livelihoods supported, not jobs created.
